# 书法临摹助手 - 项目规范

## 1. 项目概述

- **项目名称**: 书法临摹助手 (Calligraphy App)
- **项目类型**: 跨平台移动应用 (iOS/Android)
- **核心功能**: 帮助用户临摹书法作品，支持图片上传、字符选择、导航和缩放查看
- **目标用户**: 书法爱好者、学习书法的用户

## 2. 技术栈

### 2.1 前端框架
- React 18.3.1
- Vite 4.2.0

### 2.2 移动端框架
- Capacitor 6.2.0
  - @capacitor/core
  - @capacitor/cli
  - @capacitor/ios
  - @capacitor/android

### 2.3 主要依赖
- react-image-magnifiers: 图片放大镜功能
- react-icons: 图标库
- tesseract.js: OCR 文字识别 (已安装，未使用)

### 2.4 数据存储
- IndexedDB: 本地离线存储图片和历史记录

## 3. 功能规范

### 3.1 核心功能

#### 3.1.1 图片上传
- 支持格式: JPEG, PNG, GIF, WebP
- 批量上传: 最多一次5个文件
- 数据验证: 检查文件类型和 base64 格式有效性

#### 3.1.2 图片浏览
- 显示当前选中的书法图片
- 放大镜功能: 支持鼠标悬停放大查看细节
- 点击图片任意位置选择要临摹的字符区域

#### 3.1.3 字符选择
- 点击图片后显示字符选择器
- 默认字符区域大小: 图片宽度的 25%
- 支持拖动查看不同区域

#### 3.1.4 字符导航
- 上/下/左/右 微调按钮 (步长 2px)
- 上一字符/下一字符 快捷按钮
- 放大/缩小 按钮 (缩放因子 1.05)
- 相邻字符预览缩略图 (前2个、当 前、后2个)

#### 3.1.5 最近图片管理
- 自动保存最近查看的图片到 IndexedDB
- 最多保存 5 张最近图片
- 支持长按删除图片
- 图片数据持久化，刷新页面不丢失

### 3.2 用户交互

| 操作 | 功能 |
|------|------|
| 点击上传按钮 | 选择图片文件 |
| 点击最近图片 | 切换显示图片 |
| 长按最近图片 | 弹出删除确认 |
| 点击图片 | 选择字符区域 |
| 拖动字符视图 | 平移查看区域 |
| 点击导航按钮 | 切换相邻字符 |

### 3.3 数据流

```
用户上传图片 → IndexedDB 存储 → 读取显示
     ↓
点击图片 → 计算字符区域 → 显示字符选择器
     ↓
字符选择器 → 导航/缩放/拖动 → 更新 viewBox
     ↓
返回按钮 → 关闭字符选择器
```

## 5. 组件说明

### 5.1 App.jsx
- 初始化 IndexedDB 数据库
- 管理全局状态: 当前图片、选中字符、最近图片列表
- 处理图片上传逻辑
- 处理字符点击计算

### 5.2 RecentImages.jsx
- 显示/隐藏最近图片列表
- 图片上传 input
- 长按删除功能
- 删除确认弹窗

### 5.3 ImageViewer.jsx
- 显示书法图片
- 集成 Magnifier 放大镜组件
- 透明点击层捕获点击事件

### 5.4 CharacterSelector.jsx
- SVG 视图显示选中区域
- 拖动平移功能
- 导航按钮 (上下左右、微调、缩放)
- 相邻字符预览缩略图
- 返回完整图片按钮
