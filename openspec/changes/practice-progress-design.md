# 练习进度与统计 — 功能设计

> 状态：设计稿，待实现
> 前置决策：不做拍照对比（用户场景 = 手机看、纸笔写）；优先解决「练到哪了」

## 1. 要解决的问题

现状：每次打开字帖都从第一个字开始，没有任何记录。用户无法回答三个问题：

1. 这张字帖我练到第几个字了？
2. 这个字我练过几次？
3. 今天/这周我练了多少？

这不是「锦上添花」，而是工具类应用的基础留存机制——没有进度，用户每次都要自己回忆，摩擦累积后就会放弃。

## 2. 数据模型

### 新增 IndexedDB store：`practiceRecords`

DB 版本 3 → 4（`onupgradeneeded` 自动建表，老数据不受影响）

```js
// key = `${图片哈希}:${字索引}`
{
  id: 'bssf-1j3py6:5',
  imageHash: 'bssf-1j3py6',
  index: 5,
  count: 12,              // 练过次数
  lastPracticedAt: 1730..., // 最近一次时间戳
  firstPracticedAt: 1729...
}
```

外加一个轻量的每日汇总（可选，用于「今日已练 N 字」）：

```js
// key = `daily:${YYYY-MM-DD}`
{ id: 'daily:2026-11-02', count: 8, lastAt: 1730... }
```

**为什么按 `图片哈希 + 索引` 做键**：与现有 `segmentations` 一致，同一张图换位置/换设备（只要图一样）就能对上。已在 `imageHash.js` 有现成实现。

### 何时记录「练过一次」

定义为：**进入单字临摹并停留 ≥ 3 秒**（阈值已确认）。记录是**纯自动计数**，不提供手动标记/掌握状态。理由：
- 只有真正打开看过的字才算（避免滑动时误记）
- 3 秒足够读完一个字的样子，又不会因为误触记一次

实现：进入 `isCharMode` 时起计时器，切字或退出时结算。

## 3. 交互设计

### 3.1 字帖库卡片：进度条

```
┌─────────────────┐
│                 │
│   [字帖缩略图]   │
│  ━━━━━━░░░░ 12/30│  ← 新增：已练字数/总字数
│  11月2日 · 已练12 │
└─────────────────┘
```

- 进度 = 已练过的字数 / 切分总字数
- 未切分过的字帖不显示（没有总数字段可算）

### 3.2 单字临摹页：当前字状态

在顶栏标题旁显示：

```
← 单字临摹   第 6 / 30 字 · 练过 3 次
```

- 「练过 N 次」实时展示（只读，不提供手动标记）

### 3.3 切分面板：练习状态标记

在切分网格上，已练过的字给一个**淡淡的角标**（比如浅色圆点），一眼看出哪些字没碰过。

可选开关：`设置 → 显示练习标记`（默认开）。

### 3.4 统计页

```
设置 → 练习统计
┌────────────────────────┐
│ 今日  8 字              │
│ 本周 42 字              │
│ 累计 156 字             │
├────────────────────────┤
│ 各字帖进度               │
│ 字帖01  ███████░░ 12/30 │
│ 字帖02  ███░░░░░░  5/20 │
└────────────────────────┘
```

### 3.5 打开字帖时：续练

**关键体验**：`设置 → 打开时跳转到` 
- 选项 A：从第一个字开始（当前行为）
- 选项 B：**从上次练到的字继续**（默认）

实现：记录「最后练习位置」`{ imageHash, index }`，进入时若该字帖有记录就定位到那里。

## 4. 边界情况

| 情况 | 处理 |
|---|---|
| 重新切分后字索引变化 | 练习记录按索引存，框数变了会错位 → **重新切分时提示「会重置该字帖的练习记录」**，用户确认后清空 |
| 手动编辑切分框 | 同上，框顺序变化 → 清空该字帖练习记录（与现有 `adjustments` 处理一致） |
| 删除字帖 | 连带删除该图所有练习记录与每日汇总 |
| 清空全部字帖 | 清空 `practiceRecords` |
| 同一张图多次上传 | 哈希相同 → 记录共享（这是期望行为） |
| 未切分的字帖 | 不显示进度条；进入单字后才开始记录 |

## 6. 实现顺序（建议）

1. **数据层**：`practiceStore.js` + DB v4 建表 + 单元测试（纯逻辑，可测）
2. **记录时机**：`PracticeView` 进入字计时 → 写入
3. **展示**：单字页次数 → 字帖库进度条
4. **续练**：打开时定位到上次位置 + 设置项
5. **统计页**：汇总展示
6. **边界**：重切分/删除时的清理提示

## 7. 暂不做

- 「已掌握」手动标记（用户明确不需要，保持纯计数）
- 拍字对比（用户明确不需要）
- 云端同步（无上架计划）
- 社交/排行榜
- 智能推荐（没数据基础）
