# 字框编辑器交互重构 — 变更记录

## 变更信息

- **变更名称**: segment-editor-interaction
- **变更类型**: 交互 / 信息架构重构（不改功能）
- **完成时间**: 2026-11-09
- **影响范围**: `SegmentSheet.jsx`（渲染层重排）、`PracticeView.jsx`（入口与文案）、`App.jsx`（刷新时机）、`Library.jsx`（图标语义）、`index.css`（新增样式、清理废弃规则）
- **未改动**: `segment.js` 切分算法、`boxEdit.js` 纯函数、`inkProfile.js`、切分缓存键格式、`SEGMENT_ALGORITHM_VERSION`

## 背景

功能已基本完善，但用户反馈三处交互让人困惑：

1. **竖排按钮没有用** —— `LAYOUT_OPTIONS` 只剩一项「竖排」且恒选中，点击无反应，是纯死控件
2. **手动点选按钮用处不大** —— 底部主按钮文案「手动点选」，实际行为就是 `onClose` 关闭抽屉
3. **编辑加框的操作从哪里发出不明确** —— 进编辑态唯一入口是抽屉标题栏右侧 14px 的笔形图标；进入后 8 个按钮（删除/合并/拆分/加框/区域切分/切线/撤销/还原）平铺，第 9 个「找候选线」面板条件出现挤在后面

另发现两处同源问题：

- 临摹页顶部全宽按钮「自动切字，逐字临摹」语义像「开始临摹」，实际是「打开字框编辑器」，还占约 50px 高度
- 字帖卡删除图标用 `FaEllipsisH`（省略号），语义应为「更多」，点了却直接弹删除确认

## 设计

### 1. 入口：从隐藏图标改为常驻胶囊

临摹页顶栏右侧原为空占位，改为常驻入口按钮：

- 已有字框：`⊞ 字框 20`
- 无字框：`⊞ 切字`

删除顶部全宽「自动切字，逐字临摹」按钮。图区提示同步改为「轻点字格进入临摹（已切 N 字）」，
无框时「轻触选择要临摹的字，或点右上角『切字』自动切分」。

### 2. 形态：底部抽屉 → 全屏编辑页

抽屉的 84dvh 高度在编辑场景下不够用，且抽屉把手、底部「手动点选」按钮都在暗示「确认后关闭」，
与「就地编辑」的心智不符。改为全屏页，编辑页本身即编辑态，取消原来的 `editing` 开关。

顶栏结构：`‹ 返回` | `字框编辑 / N 字 · 切分来源` | `↶ 撤销`（无历史时淡显禁用）| `⋯ 更多`

### 3. 工具：8 个平铺按钮 → 4 个互斥工具

| 工具 | 图标 | 覆盖的原有操作 |
|---|---|---|
| 调整 | `FaArrowsAlt` | 选中 + 拖动 + 拉四角/四边 |
| 加框 | `FaPlus` | 单击补默认大小框 / 拖拽画框 |
| 区域 | `FaCropAlt` | 区域切分 |
| 分界 | `FaGripLines` | 本列切线 + 找候选线 |

- 同一时刻只有一个工具激活，点已激活的工具即退出、回到「调整」
- 工具下方一句话说明当前工具能做什么（320px 宽下实测均为单行）
- 删除 / 合并 / 拆分不再占工具位，改为**选中框后才出现的底部上下文操作条**：
  `第 N 个字` | 临摹此字 | 删除 | 合并 | 拆分

### 4. 低频操作收进 `⋯` 菜单

- 这张字帖带格子线（复选框，勾选后重切走格线检测）
- 重新切分
- 还原为自动切分

### 5. 顺带修复

- 字帖卡删除图标 `FaEllipsisH` → `FaTrashAlt`
- 编辑后点「临摹此字」补 `setGridVersion(v => v + 1)` —— 原先不刷新，会用编辑前的旧框坐标跳字

## 关键实现细节

### 缓存键兼容

`layout` 仍固定为 `'vertical'` 并参与缓存键 `${hash}:${layout}:${grid|free}`，
键格式不变，因此**已有切分缓存不失效**。`LAYOUT_OPTIONS` 常量与竖排/横排切换 UI 一并删除，
只留注释说明版面固定竖排的原因。

### 布局稳定性

- `.seg-page__stage` 是唯一可滚动区域；`.seg-page__stage .seg-preview` 设 `flex: 0 0 auto`，
  否则竖长条字帖会被 flex 收缩、`overflow:hidden` 裁掉下半部分（实测 155×745 的竖条：
  修复前 `stageScrollH=700` 不可滚，修复后 `stageScrollH=1779` 可滚）
- 图区顶部对齐（`margin: 0 auto`）而非垂直居中，底部操作条出现/消失时图片不上下跳
- `.seg-context__actions` 用 `grid` 四等分 + 图标在上文字在下，390px/320px 下均单行不换行
- `.seg-cut-bar` 改 `grid`：编号 chips 独占第一行、两个按钮等分第二行（原 flex+wrap 在 320px 下错位）
- `.seg-menu__row input` 自绘复选框（`appearance: none`），否则深色主题下是白色大方块
- 新增 `.btn:disabled` 与 `.seg-page__bar .icon-btn:disabled`，禁用态明显淡显且不响应点击

### 清理

删除仅旧抽屉使用的样式：`.stage-actions`、`.segmented` / `__item` / `--active`、`.seg-toggle`、
`.seg-edit-bar` 及子规则、`.seg-edit-hint`、`.seg-btn--active`、`.seg-page__tip`。
`.sheet` / `.sheet__*` 保留（`ImportSheet.jsx` 仍在用）。

## 验证

`npm test` 25 项全通过；`npm run build` 通过。

用无头 Chrome + CDP 在真实应用上做功能回归（390×844 与 320×568 各一遍，`logs: (none)`）：

| 项目 | 结果 |
|---|---|
| 顶栏入口文案 | 「字框 31」/ 无框时「切字」 |
| 图区提示 | 「轻点字格进入临摹（已切 31 字）」 |
| 加框工具 | 框数 31→32，工具保持「加框」高亮（连续补框） |
| 撤销 | 32→31，撤销按钮 `disabled=true` |
| 选中框 | 底部条显示「第 4 个字」 |
| 删除 / 拆分 / 合并 | 31→30 / 30→31 / 31→30 |
| `⋯` 菜单 | 3 行，复选框可勾选 |
| 区域切分 | 拖出矩形后显示「区域切分 · 2 条候选线」 |
| 临摹此字 | 进入「单字临摹」，`gridVersion` 刷新后「下一字」按新框跳转 |
| 横向溢出 | `overflowX=false`（320px 与 390px） |
| 浅色 / 深色主题 | 均正常 |
| 竖长条字帖 | 图区可滚动到下半部分 |

## 遗留

- 编辑页未做「首次进入引导」（手势提示层）
- 区域切分、分界两个工具的候选线面板共用同一套 chips 样式，未针对工具做视觉区分
