## Context

书法临摹助手当前需要用户手动点击图片选择字符，操作不够便捷。tesseract.js 已安装但未使用。项目需要集成 OCR 文字识别功能，自动识别图片中的书法文字。

## Goals / Non-Goals

**Goals:**
- 自动识别上传图片中的书法文字
- 显示识别结果供用户选择
- 识别后可直接跳转到对应字符区域进行临摹
- 支持中文和英文识别

**Non-Goals:**
- 不实现手写识别（用户自己的字）
- 不实现整幅作品的自动分割（单字识别）
- 不支持服务器端识别（纯客户端实现）

## Decisions

### 1. OCR 引擎选择
- **决定**: 使用 tesseract.js (已安装)
- **理由**: 纯客户端方案，无需后端，支持多语言

### 2. 图片预处理
- **决定**: 实现灰度化和对比度增强预处理
- **理由**: 书法图片多为黑白或浅色底，预处理可提高识别率

### 3. 识别触发时机
- **决定**: 用户上传图片后自动识别
- **理由**: 用户体验更流畅，识别完成后直接显示结果

### 4. 识别结果显示
- **决定**: 显示识别文字列表 + 对应位置标记
- **理由**: 用户可快速选择要临摹的字符

## Risks / Trade-offs

- [风险] 书法文字识别准确率可能不高 → 书法字体多样，OCR 识别有局限性，提供手动选择作为备选
- [风险] 识别速度可能较慢 → 显示加载状态，支持后台识别
- [权衡] 纯客户端识别受限于浏览器性能，大图可能需要压缩处理
