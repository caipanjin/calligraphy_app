# 界面重构：现代水墨 - 变更记录

## 变更信息

- **变更名称**: ui-redesign
- **变更类型**: 界面 / 信息架构重构
- **完成时间**: 2026-11-01
- **影响范围**: 全部前端组件（App / 5 个组件 / 样式体系），OCR 与 IndexedDB 逻辑保留

## 背景

原界面是「单页堆叠」结构：标题 + 折叠的「最近图片」+ 图片 + 字符选择器依次向下排列，
所有控件用内联样式和系统默认按钮，缺乏层级、导航与触控优化。用户反馈"UI 太粗糙简单"，
要求参考成熟应用重做，而非仅调色。

## 设计方向

**现代水墨**：宣纸暖底 + 墨色文字 + 朱砂点缀，衬线标题（宋体）+ 无衬线正文，大留白、圆角卡片。

## 结构与交互变更

### 1. 信息架构

- 由「单页堆叠」改为「Tab + 沉浸式页面」：
  - 字帖库（Tab）：2 列卡片网格、空状态引导、添加入口
  - 临摹页（全屏）：图片舞台 → 单字临摹，两级返回
  - 设置（Tab）：外观 / 数据 / 关于 / 快捷键
- 识别入口从「上传即自动识别」改为临摹页右上角按钮，结果以底部抽屉呈现

### 2. 组件重构

| 原组件 | 现组件 | 变化 |
|---|---|---|
| App.jsx（373 行） | App.jsx + 5 个组件 | 拆分为库 / 临摹 / 抽屉 / 设置 / 提示 |
| RecentImages.jsx | Library.jsx | 折叠列表 → 卡片网格；长按删除 → 卡片菜单 + 确认弹窗 |
| ImageViewer.jsx | PracticeView.jsx | 合并进临摹页舞台 |
| CharacterSelector.jsx（519 行） | PracticeView.jsx + utils/charNav.js | 导航算法抽为纯函数，UI 重做 |
| OCRResults.jsx | OCRSheet.jsx | 居中弹窗 → 底部抽屉 + 分段视图 |

### 3. 交互增强

- 单字临摹支持**双指缩放**（原仅拖动）
- 工具栏改为 5 键底部 dock，微调改为浮层方向盘（原为 3×3 常驻网格）
- 字符滑轨保留前 2 / 后 2 缩略图，当前字高亮
- 桌面端快捷键：方向键微调、`+/-` 缩放、PageUp/PageDown 换字、Esc 返回
- 米字格辅助线、空状态、轻提示（替代 `alert`）

### 4. 设计系统

- `index.css` 重写为令牌驱动：色彩 / 字体 / 圆角 / 阴影 / 安全区
- 浅色与深色双主题，默认跟随系统，可在设置中切换并持久化
- 统一触控热区（图标按钮 44px、卡片菜单 34px 视觉 + 44px 热区）
- 次要文字对比度提升至 AA（浅色 4.76:1、深色 5.58:1）

## 顺带修复

- 点选单字时统一使用**图片原始坐标**（原实现用 CSS 像素作为 width/height，与 OCR 路径的原始坐标不一致）
- 缩放 / 平移增加边界钳制，避免拖出图片外
- 拖动换算改用实际渲染宽度（原写死 `VIEWPORT_SIZE = 360`）
- 删除字帖改为整表重写，避免原「清空后重排」的非原子操作

## 验证

- 构建通过；`dist` 约 13MB（含 OCR 资源）
- 布局审计（390×844 视口）：无横向溢出、无文字裁切、工具栏不越界、抽屉占屏 50%
- 对比度审计：浅色 / 深色 / 抽屉三种场景均无 AA 违规
- 交互回归 13 项全部通过：上下字、缩放、方向盘 +2px、滑轨跳转、键盘、双指缩放、拖动、Esc
- 界面截图见 `docs/screens/`

## 遗留

- 无手势提示层（首次进入单字模式未引导双指缩放）
- 字帖卡片未支持重命名 / 排序
- 图片模式的放大镜为桌面悬停交互，移动端无等效替代
