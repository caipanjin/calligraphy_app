# 界面重构：现代水墨 - 变更记录

## 变更信息

- **变更名称**: ui-redesign
- **变更类型**: 界面 / 信息架构重构
- **完成时间**: 2026-11-01
- **影响范围**: 全部前端组件（App / 5 个组件 / 样式体系），OCR 与 IndexedDB 逻辑保留

## 背景

原界面是「单页堆叠」结构：标题 + 折叠的「最近图片」+ 图片 + 字符选择器依次向下排列，
所有控件用内联样式和系统默认按钮，缺乏层级、导航与触控优化。用户反馈"UI 太粗糙简单"，
要求参考成熟应用重做，而非仅调色。

## 设计方向

**现代水墨**：宣纸暖底 + 墨色文字 + 朱砂点缀，衬线标题（宋体）+ 无衬线正文，大留白、圆角卡片。

## 结构与交互变更

### 1. 信息架构

- 由「单页堆叠」改为「Tab + 沉浸式页面」：
  - 字帖库（Tab）：2 列卡片网格、空状态引导、添加入口
  - 临摹页（全屏）：图片舞台 → 单字临摹，两级返回
  - 设置（Tab）：外观 / 数据 / 关于 / 快捷键
- 识别入口从「上传即自动识别」改为临摹页右上角按钮，结果以底部抽屉呈现

### 2. 组件重构

| 原组件 | 现组件 | 变化 |
|---|---|---|
| App.jsx（373 行） | App.jsx + 5 个组件 | 拆分为库 / 临摹 / 抽屉 / 设置 / 提示 |
| RecentImages.jsx | Library.jsx | 折叠列表 → 卡片网格；长按删除 → 卡片菜单 + 确认弹窗 |
| ImageViewer.jsx | PracticeView.jsx | 合并进临摹页舞台 |
| CharacterSelector.jsx（519 行） | PracticeView.jsx + utils/charNav.js | 导航算法抽为纯函数，UI 重做 |
| OCRResults.jsx | OCRSheet.jsx | 居中弹窗 → 底部抽屉 + 分段视图 |

### 3. 交互增强

- 单字临摹支持**双指缩放**（原仅拖动）
- 工具栏改为 5 键底部 dock，微调改为浮层方向盘（原为 3×3 常驻网格）
- 字符滑轨保留前 2 / 后 2 缩略图，当前字高亮
- 桌面端快捷键：方向键微调、`+/-` 缩放、PageUp/PageDown 换字、Esc 返回
- 米字格辅助线、空状态、轻提示（替代 `alert`）

### 4. 设计系统

- `index.css` 重写为令牌驱动：色彩 / 字体 / 圆角 / 阴影 / 安全区
- 浅色与深色双主题，默认跟随系统，可在设置中切换并持久化
- 统一触控热区（图标按钮 44px、卡片菜单 34px 视觉 + 44px 热区）
- 次要文字对比度提升至 AA（浅色 4.76:1、深色 5.58:1）

## 顺带修复

- 点选单字时统一使用**图片原始坐标**（原实现用 CSS 像素作为 width/height，与 OCR 路径的原始坐标不一致）
- 缩放 / 平移增加边界钳制，避免拖出图片外
- 拖动换算改用实际渲染宽度（原写死 `VIEWPORT_SIZE = 360`）
- 删除字帖改为整表重写，避免原「清空后重排」的非原子操作

## 验证

- 构建通过；`dist` 约 13MB（含 OCR 资源）
- 布局审计（390×844 视口）：无横向溢出、无文字裁切、工具栏不越界、抽屉占屏 50%
- 对比度审计：浅色 / 深色 / 抽屉三种场景均无 AA 违规
- 交互回归 13 项全部通过：上下字、缩放、方向盘 +2px、滑轨跳转、键盘、双指缩放、拖动、Esc
- 界面截图见 `docs/screens/`

## 第二轮：布局缺陷修复（模型无法读图后的替代验证）

因当前模型不支持图片输入，改用 DOM 盒模型审计 + 像素级扫描替代"看截图"，发现并修复：

| 问题 | 现象 | 修复 |
|---|---|---|
| 字帖网格列宽不等 | 实测 133px vs 213px（应为 173px），`aspect-ratio` 撑破了 `1fr` 的自动最小尺寸 | 改为 `minmax(0, 1fr)` + 网格项 `min-width: 0`，添加卡改用 `align-self: stretch` |
| 临摹页大片死空间 | 图片模式上下各 150px、单字模式画布与滑轨间 150px 空白 | 内容改为「分组居中」：组内间距固定，多余空间对称分到组外；单字页间距降到 0 |
| 死空间未利用 | 图片模式空白区域无信息 | 新增「最近字帖」快捷切换条 + 底部「识别文字」主按钮 |
| 单字页缺乏全局定位 | 放大后不知道处在整幅字的哪个位置 | 新增全景缩略导航：显示整幅图 + 当前选区框，点击可跳转 |
| 间距不成体系 | 出现 3/6/9/11/14/22px 等非栅格值 | 关键间距归到 4/8 栅格（卡片内边距 12、工具栏 8、抽屉把手 8、文字块 8/12） |

验证：网格 4 项等宽（173px）、像素扫描首行两块差 0.5px、交互回归 13/13 通过、无运行时异常。

## 第三轮：iOS 安全区适配

真机反馈「返回按钮跑到顶部，和状态栏时间重叠」。

原因：`index.html` 设置了 `viewport-fit=cover`（让页面延伸到刘海/灵动岛下方），
但样式只处理了 `env(safe-area-inset-bottom)`，**漏了顶部**，导致顶栏内容压到状态栏下面。

修复：

- 新增 `--safe-top: env(safe-area-inset-top, 0px)`
- `.app-header`：`height` 改为 `min-height: calc(56px + safe-top)`，并加 `padding-top: safe-top`
- `.practice__bar`：`padding-top: calc(6px + safe-top)`

验证（模拟 iPhone 15 Pro：safe-top 59 / safe-bottom 34）：

| 项目 | 结果 |
|---|---|
| 库页顶栏高度 | 115px = 56 + 59 ✅ |
| 标题 / 图标 top | 65px（在状态栏之下）✅ |
| 临摹页返回按钮 top | 65px ✅ |
| Tab 栏高度 | 94px = 60 + 34 ✅ |
| 单字页工具栏距底 | 46px（34 安全区 + 12 内边距）✅ |
| 普通浏览器（无安全区） | 顶栏仍为 56px，无回归 ✅ |

## 遗留

- 无手势提示层（首次进入单字模式未引导双指缩放）
- 字帖卡片未支持重命名 / 排序
- 图片模式的放大镜为桌面悬停交互，移动端无等效替代
